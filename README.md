# SmartStudy - HTML Student Project

A small responsive HTML/CSS/JavaScript project suitable for practicing Git and GitHub.

## Files
- index.html
- style.css
- script.js

## Suggested Git assignment
1. Upload the project to GitHub.
2. Edit one HTML comment, for example:
   `<!-- Main navigation section -->`
3. Save the file.
4. Run:
   `git add .`
5. Commit:
   `git commit -m "Update HTML comment"`
6. Push:
   `git push origin main`
